# The Self-Checkout Is Judging You

make.fun bounty entry. `main.ts` (Node 22, stdlib only) writes one funny line in the voice of a smug, judgmental self-checkout machine to `entry.txt`.

> Ice cream, frozen peas, and a single candle. I am not judging you. I am just telling the next customer.

Run with `MAKEFUN_OUTPUT_DIR` set to choose the output directory (defaults to `/output`).
